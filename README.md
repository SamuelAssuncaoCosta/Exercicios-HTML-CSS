Exercícios – Curso de HTML, CSS e JavaScript 

Este repositório reúne os exercícios, desafios e projetos desenvolvidos durante o Curso de HTML5, CSS3 e JavaScript – Módulo 1, ministrado pelo professor Gustavo Guanabara, do Curso em Vídeo.

Objetivo:

Praticar os conceitos fundamentais de desenvolvimento web, aplicando na prática conteúdos como:

Estruturação de páginas com HTML5;
Estilização com CSS3;
Boas práticas de organização de código;
Introdução ao JavaScript;
Desenvolvimento de páginas responsivas e semânticas.

Este repositório faz parte da minha jornada de aprendizado em desenvolvimento web e será atualizado conforme avanço no curso.
